## 实现思路

1. 识别页面使用的前端运行时、资源与 WebGL 动画依赖，明确需要捕获的页面和交互状态。
2. 通过浏览器捕获页面及已访问状态的资源响应，归档原始内容和请求映射。
3. 在本地提供资源回放，并针对站点运行时进行适配。
4. 对照原站检查页面布局、资源加载与粒子渲染效果，针对差异继续修复。

## 关键问题：粒子效果偏稀疏

最初复刻出来时，我发现粒子明显少了一截，亮度和光晕也比原站弱。排查渲染配置后，我针对这个站点调整了质量分档、粒子预算和后处理设置，再与原站对照，补齐了这部分效果。

这也是我做这个案例时重点解决的一个问题：除了把资源完整搬下来，还要检查运行时实际用了什么渲染配置，才能把动画效果还原到位。

我从零设计并开发了这套 Skill，把网站识别、浏览器捕获、资源归档、本地回放和验证补抓整理成可重复使用的流程，并用这个案例完成实战验证，解决了运行时适配和粒子效果还原的问题。
