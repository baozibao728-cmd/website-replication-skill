# OpenAI GPT-6 Astra 页面复刻

使用本仓库的 Skill 对 [OpenAI GPT-6 Astra 页面](https://openai.com/index/gpt-6-astra/)进行高保真镜像复刻，优先复用原站前端资源与运行时，在本地回放页面。

## 实现思路

1. 识别页面使用的前端运行时、资源与 WebGL 动画依赖，明确需要捕获的页面和交互状态。
2. 通过浏览器捕获页面及已访问状态的资源响应，归档原始内容和请求映射。
3. 在本地提供资源回放，并针对站点运行时进行适配。
4. 对照原站检查页面布局、资源加载与粒子渲染效果，针对差异继续修复。

## 关键问题：粒子效果偏稀疏

初版镜像的粒子可见密度、亮度和光晕明显弱于原站。排查后，通过站点专用适配调整渲染质量配置，启用更高的粒子预算与完整后处理，再对照截图检查效果。

这次修复说明：资源成功加载不等于视觉复刻完成。WebGL 页面的设备质量分档、粒子预算和后处理设置同样需要核对。该适配属于本案例的站点实现，并非通用 Skill 自动适用于所有网站的功能。

## 项目贡献与展示范围

本项目的工作在于设计和实现复刻工作流、捕获与归档工具、本地回放和验证，以及定位、修复镜像中的视觉差异。原站页面设计、品牌与粒子动画资源来自 OpenAI。

此目录提供截图对比与案例说明；完整镜像资源、站点适配代码和演示视频未包含在本目录中。
