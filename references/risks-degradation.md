# 缺口与降级

| 实际问题 | 处置 |
|---|---|
| HTML 冒充资源 | 联合状态、类型、正文和格式签名判断；不登记完成 |
| HAR缺响应体 | 优先重新录制，必要时显式 --fetch-missing 仅补GET并记录版本变化 |
| 同请求响应冲突 | 选一致版本、设备或数据状态重新捕获，不静默覆盖 |
| 下载不完整/超时 | 有界重试；失败不落为有效文件，保留原因 |
| 首页正常其他状态缺素材 | 根据覆盖报告补明确动作 |
| 403/429/挑战 | 降速、等待或使用任务允许的正常浏览器访问；持续失败记录阻塞 |
| 核心JS/WASM/模型缺失 | 关键状态未通过，只交付部分；占位不计完整 |
| 可选图片/音频缺失 | 目标允许时用占位/静音，记录差异 |
| 外网逃逸 | 检查映射、动态URL、CSS、CSP/SRI和Worker，修复后重验 |
| API未录/签名不匹配 | 返回明确错误/演示空态，不转发真实接口 |
| 无浏览器环境 | 可交付明确清单归档，不称交互与视觉已验收 |

到达预设路由/动作/请求预算仍缺关键状态，或缺必要输入/访问能力时，报告已完成部分、证据和具体缺口。完成与部分完成要区分。

保留原始归档字节，域名改写、CSP/SRI调整、mock和静态降级需可追溯。公开发布、品牌替换或账号状态只处理已有授权范围，不增加固定开场声明与重复确认。
