# 指纹识别与范围确认

运行 node scripts/fingerprint.js <url>，保存 JSON 或记录结论。它检查入口、随机不存在路径与有限脚本；不枚举全部路由。

1. 官方源码需核对作者、demo、分支与线上版本；获取后仍需构建验证。
2. 资源按最终文档 URL、base 元素和所属脚本 URL 解析，不能简单拼域名。
3. SSR 水合、模块入口、WebGL/解码器和运行时网络行为共同决定手册。HTML 大小仅辅助。
4. fetch() 可能用于模型或模块加载，不能直接判为业务 API。
5. 登录、无限列表、搜索组合等需限定交付样本与边界。

## soft-404

随机不存在路径返回 200 + HTML，只证明该路径有 soft-404；不同目录/CDN可能不同。记录状态、类型、大小、bodySha256，必要时补具体资源命名空间探针。

不能因为平台常有回退就忽略状态码，也不能按文件小拒绝正常首页或图标。资源请求返回 HTML 应判异常；合法页面单独处理。

可把 JSON 传给 archive 的 --fingerprint 参数，辅助排除与探针正文一致的资源响应。该哈希不用于拒绝正常页面外壳。

## 人工复核

运行时拼接、编码 manifest、间接 import 用浏览器实际请求补证据；按交互加载的资源需补明确动作。unknown 或冲突信号应查看 DOM/Canvas/Network，不凭体积硬分类。

公开 source map 可能包含源码，但不保证构建配置、全部依赖与原始工程可得。不要把某两个示例站的表现当通用上限。
